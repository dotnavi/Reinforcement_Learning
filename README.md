# Reinforcement Learning Labs

This repository contains implementations and experiments completed as part of the Reinforcement Learning lab.

## Contents

- **CartPole** – Gymnasium environment setup and random agent experiment.
- **Tic-Tac-Toe** – Value Function Learning and Temporal Difference learning.
- **GridWorld** – Policy Evaluation, Value Iteration, and policy comparison.

## Tools Used

- Python
- Gymnasium
- NumPy
- Matplotlib

Each folder contains the corresponding code and/or lab work.
